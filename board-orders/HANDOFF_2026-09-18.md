## 7. Texas (added by the evening session)

The survey's Tier 3 rating was wrong. BHEC's website has no enforcement
list and its licensee lookup is reCAPTCHA-protected (no script or headless
browser gets past it), but the Council's quarterly "Public Meeting
Materials" packets contain the signed agreed orders for every profession,
and they are plain files behind one static page. `texas_downloader\`
reads the 17 packets (about 950 MB, thrown away after extraction) and
writes one PDF per LPC order: 171 files, 166 people, June 2021 to May 2026,
all on `board-orders-data` under `Texas\`. Limits: agreed orders only (no
default or SOAH orders), nothing before June 2021, and 161 of 171 are
scans. Older and contested-case orders need a Public Information Act
request to Open.Records@bhec.texas.gov; BHEC's daily LPC.csv
(Discpl_Actn=Yes, 301 current licensees, 197 of them without an order in
the packets) is the name list to ask about. Re-run after each Council
meeting (February, June, October); only the new packet is fetched. Full
write-up: `TEXAS_VERIFICATION_2026-09-18.md`.

## 8. Colorado (added by the same evening session as Texas)

The survey's Tier 2 "roster, then per-licensee lookup" picture was half
right. The roster generator (apps2.colorado.gov, ASP.NET, no CAPTCHA)
gives the index: 20,098 LPCs, 557 with a public action, 910 action rows
with case number, action label and dates. The per-licensee lookup is not
usable (Amazon WAF CAPTCHA on apps.colorado.gov, a form CAPTCHA on apps2)
and not needed: DORA's separate "DPO Public Documents System" (DDMS,
www.dora.state.co.us/pls/real) lists every document filed under the
counselor board in one query, with plain PDF links. `colorado_downloader\`
does roster -> DDMS -> download: 898 documents listed, 774 counselor
files (612 people, 1992-08 to 2026-06), 774 downloaded with 0 failures,
976 MB, 196 text-native and 578 scans, all on
`board-orders-data` under `Colorado\`. Limits: the documents before about
2019 are image scans; 19 roster actions (12 people, mostly 1990s) have no
document in DDMS; 102 files matched no roster action on date and carry no
case number in the manifest (it is inside the PDF). The 92 LPCC (candidate)
documents were listed but not fetched (`--include-candidates`). Re-run any
time; only new files are fetched. Full write-up:
`COLORADO_VERIFICATION_2026-09-18.md`.

## 9. California (added 2026-09-19)

The survey's Tier 2 MODERATE was too hopeful. The BBS enforcement page
(`bbs.ca.gov/consumers/enforcement_actions.html`) is the text of one
month's subscriber e-mail: names with license type and number, grouped by
Citations, Accusations, Decisions and Petitions, no dates, no links, no
archive (earlier months exist only as Wayback Machine captures, one-month
layout back to 2017; LPCC and APCC entries run 0 to 2 a month). The full
documents (Accusation, Stipulated Settlement, Decision) are on the DCA
License Search (`search.dca.ca.gov`), whose Advanced Search can list every
LPCC with "Has Discipline = Yes", but the search form is a Cloudflare
Turnstile CAPTCHA, the detail and download addresses carry opaque tokens
that cannot be derived, and the site's robots.txt disallows `/details/` and
`/download*`. No search was submitted and nothing was fetched. The one
scripted route is DCA's official iServices Search API
(`iservices.dca.ca.gov`: sign up, create an application with a
justification, wait for DCA approval, then APP_ID and APP_KEY headers); it
returns every licensee of a type with hasDiscipline and hasDocuments flags
and the public record actions per license, though whether it also serves
the PDFs is not stated. Rating HARD; no `california_downloader\`; nothing
on the data branch. **Decision 2026-09-19 (Richard): California is skipped.**
The project collects only orders a board lists publicly on its website,
and California does not. The API sign-up, the by-hand steps and the Public
Records Act wording are kept in `CALIFORNIA_VERIFICATION_2026-09-19.md` for
reference only; none of them is being pursued.
