## 3. Suggested order of work (laptop or desktop, one machine at a time)

1. Kansas: `py download_kansas_orders.py --list-only`, open manifest.csv,
   confirm counselor rows and names, then double-click the run file.
2. New Hampshire: same two steps. Expect a small number of LCMHC orders.
3. Vermont: run the .cmd. If it cannot list the folder, open the folder URL
   in a browser and adjust `FOLDER` / `WEB_ROOTS` in the script. After the
   run, Foxit-OCR `state_data\Vermont\review\` and run `--reclassify`.
4. Iowa: `py download_iowa_orders.py --list-only --max-pages 5`, open actions.csv,
   check the relevant flag and PDF links, then run the .cmd; OCR `review\` and
   `--reclassify` as for Vermont.
5. For each state after download: `py make_text_sidecars.py --states <State>`,
   register the state in `PDF_STATES` in `board_order_extractor.py`, run the
   extractor from ONE machine, spot-check rows.
6. Then the items carried over from 9-17: Ohio bundled-PDF rows, taxonomy
   decision from the literature crosswalk, rebuild the pipeline scripts and
   regenerate the package.
